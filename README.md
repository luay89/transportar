# Transportar

تطبيق ويب تقدّمي (PWA) لشركة نقل بسائق في أمريكا. العميل يمسح رمز QR من بطاقة أو منشور أو ملصق أو ستاند فندق، فيفتح صفحة الحجز مباشرة على الهاتف أو الآيباد أو اللابتوب أو الشاشة الذكية، ويمكن إضافتها للشاشة الرئيسية كتطبيق بدون تحميل من المتجر.

A QR-to-ride Progressive Web App for a US chauffeur/transportation business, built to grow into a multi-company SaaS.

**جرّبه الآن:** https://luay89.github.io/transportar/ (نسخة تجريبية كاملة تعمل في المتصفح)

## التجربة

النسخة التجريبية تعمل كاملة داخل المتصفح مع بيانات 4 أسابيع نموذجية:

| الدور | الرابط | الدخول |
|---|---|---|
| العميل | `/` أو `/?c=hilton` | — |
| السائق | `/#driver` | PIN 1111 أو 2222 |
| المالك | `/#admin` | admin123 |
| بوابة الشركات | `/#company` | ACME / acme123 |
| المنصة | `/#platform` | platform123 |

## التشغيل

Node.js 18 أو أحدث. لا يحتاج أي حزمة لتشغيله؛ حزمة Anthropic اختيارية للمساعد الذكي.

```bash
npm install          # اختياري: يثبت @anthropic-ai/sdk لمساعد Claude
ADMIN_PASSWORD='choose-a-strong-one' PLATFORM_PASSWORD='another-one' npm start   # http://localhost:3000
npm test             # اختبار المسار الكامل عبر الـ API
npm run build:demo   # dist/demo.html نسخة تجريبية تعمل بلا خادم (انسخها إلى docs/index.html لتحديث GitHub Pages)
```

| المتغير | الوصف |
|---|---|
| `PORT` | المنفذ (الافتراضي 3000) |
| `DATA_FILE` | مسار ملف البيانات (الافتراضي `data/db.json`) |
| `PUBLIC_URL` | رابط الموقع العام، لروابط الدفع والعودة |
| `ADMIN_PASSWORD` | كلمة مرور مالك الشركة الافتراضية (مطلوبة قبل الإطلاق) |
| `PLATFORM_PASSWORD` | كلمة مرور لوحة المنصة (مطلوبة قبل الإطلاق) |
| `ANTHROPIC_API_KEY` | يفعّل مساعد الحجز ونصائح التحليلات بـ Claude |
| `AI_MODEL` | نموذج Claude (الافتراضي `claude-opus-5-5`) |
| `STRIPE_SECRET_KEY` | يفعّل الدفع بالبطاقة وApple Pay وGoogle Pay |
| `STRIPE_WEBHOOK_SECRET` | للتحقق من إشعارات Stripe على `/api/stripe/webhook` |
| `FLIGHT_API_KEY` | مفتاح AviationStack لتتبع الرحلات تلقائياً |
| `DEMO_PAYMENTS` | `1` لتجربة شاشة الدفع بالبطاقة بدون Stripe |

## النشر

أي استضافة تشغّل Node مع قرص دائم (Render، Railway، Fly.io، DigitalOcean، VPS). يجب أن يكون الرابط HTTPS ليعمل التثبيت وتحديد الموقع. خذ نسخة احتياطية من ملف البيانات.
لكل شركة إضافية: تُفتح على `?co=اسمها`، أو على نطاقها الخاص بعد توجيه DNS إلى الخادم (يتعرف الخادم على النطاق تلقائياً).

## البنية

```
server.js              خادم HTTP: الملفات الثابتة، /api، manifest لكل شركة، Stripe، فحص الرحلات
server/ai.js           مساعد الحجز ونصائح التحليلات (Claude)
server/stripe.js       Stripe Checkout والتحقق من الإشعارات
server/flights.js      تتبع الرحلات (AviationStack)
public/core/           منطق العمل المشترك بين الخادم والنسخة التجريبية
  pricing.js           التسعير والكوبونات والمستويات
  dispatch.js          التوزيع الذكي
  nlp.js               فهم الطلب المكتوب بدون ذكاء اصطناعي خارجي
  analytics.js         التحليلات والنصائح
  core.js              الشركات، الحجوزات، العملاء، السائقون، الصلاحيات، الـ API
public/js/             الواجهة: الحجز، التتبع، السائق، لوحة المالك، المنصة، اللغات
public/styles.css      التصميم (فاتح/داكن، عربي RTL، جوال)
public/vendor/         qrcode-generator (MIT) و Leaflet (BSD-2) للخرائط
scripts/               اختبار الـ API وبناء النسخة التجريبية
```

## خطة التطوير التالية

- رسائل SMS وواتساب للعميل والسائق عند كل تغيّر في الحالة (Twilio).
- فوترة الاشتراكات للشركات على المنصة (Stripe Billing) وصفحة تسجيل ذاتي.
- حساب المسافة والوقت بالطريق الفعلي (Google Maps أو Mapbox) بدل التقدير الخطي × 1.3.
- قاعدة بيانات Postgres عند تجاوز بضعة آلاف حجز شهرياً.
- تطبيقات متجر (iOS/Android) بنفس الكود عند الحاجة، عبر Capacitor.
- أدوار إضافية في الشركة (موظف توزيع، محاسب).
